# Vibe Keyboard
Material You клавиатура (Kotlin + Jetpack Compose).

1. Открой папку в Android Studio (Ladybug+), дождись Gradle sync (wrapper сгенерится сам).
2. Run на устройство/эмулятор с Android 12+ (динамические цвета).
3. В приложении: "Включить в настройках" -> включи Vibe Keyboard -> "Выбрать клавиатуру".
